# Architectural Fitness Functions

- `definitions/`: regras executáveis versionadas por categoria.
- `waivers/`: exceções aprovadas e temporárias. Somente arquivos `.yaml`, `.yml` e `.json` são carregados.
- `examples/`: modelos que não são executados automaticamente.

Copie `examples/architecture-waiver.example.yaml` para `waivers/` somente após preencher aprovação, alvo, ADR e validade.
